# CSC584-Individual-Assignment- Personal Profile Web Application

## Description
A simple web application that collect personal profile info which includes Name, Student ID, Programme, Email, Hobbies, and a Short Self-Introduction through an HTML form, sends it to a Servlet using HTTP POST, and displays it on a JSP page.

## Technologies used
- HTML5, CSS3
- Java Servlet (javax.servlet)
- JavaServer Pages (JSP)
- Apache NetBeans IDE
- Apache Tomcat 9
- JDK 8

## How to Run
1. Install JDK 8 and Apache NetBeans.
2. Download Apache Tomcat 9 and add it in NetBeans
   (Tools > Servers > Add Server > Apache Tomcat or TomEE).
3. In NetBeans, choose File > Open Project and select the 'PersonelProfile' folder.
4. Right click the project > Clean and Build.
5. Right click the project > Run.
6. Open http://localhost:8081/PersonalProfile/ (change the port 8081 to if 
   the previous Tomcat uses 8080).
